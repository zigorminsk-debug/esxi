# ESXi RAID Assistant 0.2.1 — предварительная версия

## Исправлено подключение

- Введите IP-адрес ESXi, логин и пароль и нажмите **«Подключиться»**. Отдельный файл сертификата или ручной ввод отпечатка для обычного подключения не требуются.
- Для самоподписанного или недействительного по времени сертификата программа объясняет риск и спрашивает разрешение. Отмена останавливает вход до отправки пароля. Продолжайте только в доверенной сети: без независимой проверки сервер может быть подменён, а пароль перехвачен.
- Прогресс и понятные ошибки подключения/входа отображаются рядом с кнопкой. Пароль очищается из поля, не записывается в профиль и не попадает в отчёты. Предыдущие результаты убираются при смене хоста или новой попытке.
- При желании можно ввести независимо проверенный SHA-256 в дополнительных настройках. Полученный автоматически отпечаток закрепляется только на время попытки и не подтверждает личность сервера при первом соединении.

Сохранены импорт RAID-отчётов, необязательное read-only SSH, диагностика LSA/LWA и порт 35557, мониторинг и каталог 22 расширений ESXi. Программа не устанавливает пакеты и не изменяет сервер автоматически. Совместимость контроллера, firmware и пакета нужно проверять отдельно.

Windows 10/11 x64 и WebView2 Runtime. Проверки включают Go/симулятор, 14 браузерных сценариев и реальное окно Windows WebView2 с нажатием формы и локальным симулятором. **Реальный ESXi и RAID-контроллер для испытания не предоставлялись.** EXE подписан публичным лабораторным сертификатом из репозитория; подпись не доказывает подлинность издателя, возможны предупреждения SmartScreen. Обновление — вручную.
