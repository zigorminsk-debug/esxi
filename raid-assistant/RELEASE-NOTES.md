# ESXi RAID Assistant 0.2.0 — предварительная версия

Отдельная программа Windows x64 для обследования ESXi 8 и подготовки **ручной** установки совместимого Broadcom LSA/LWA. Для поддерживаемого контроллера и корректно настроенного агента доступ может открываться по `https://IP-ESXi:35557`; это не универсальный порт RAID.

### Добавлено

- Импорт отчётов StorCLI/StorCLI2 JSON и HPE SSACLI TXT; необязательное SSH-чтение фиксированными командами после явного разрешения и независимой сверки host key.
- Мастер диагностики VIB `lwmd`, службы, firewall, TCP/TLS и HTTP. Открытый порт не доказывает работу LSA или здоровье RAID.
- Подсказки для Dell/HPE/Lenovo и каталог **22 возможностей ESXi**: Broadcom NIC/HBA/RAID, VMware Tools, NVMe, vSAN, NSX, HA, Replication, OEM-пакеты, vGPU и CDP. Описание и официальные источники: `ESXI-8-EXTENSIONS.md`.
- Осторожное сопоставление RAID → VMFS → видимые ВМ только по уникальному точному NAA; история, список хостов без паролей, мониторинг при открытой программе и необязательные системные уведомления.
- Проверка новых релизов с ручной загрузкой, копирование команд, сохранение инструкции, подтверждаемая отправка в Telegram, реальные иллюстративные скриншоты с указанием источника и импорт собственного снимка.

Программа не устанавливает VIB, не изменяет RAID/firewall, не включает SSH и не перезагружает сервер. Подбор LSA ограничен четырьмя моделями и ESXi 8.0 U1/U2/U3; модель, firmware, конкретный build, OEM и подпись обязательно проверяются отдельно. Импорт/SSH поддерживают не все варианты вывода, а снимок может быть неполным или устаревшим. Мониторинг порта не заменяет мониторинг дисков; SSH-пароль мониторинга находится только в памяти до остановки. Подробный порядок — в `README-RAID-Assistant.md`.

Требуются Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Сборка и автоматические проверки выполнены GitHub Actions, включая Windows WebView2 smoke; **реальный ESXi и RAID-контроллер для испытания не предоставлялись**. Начинайте с тестовой среды и проверенных резервных копий.

EXE подписан публичным лабораторным сертификатом из репозитория по решению владельца. Подпись и опубликованная рядом контрольная сумма не доказывают подлинность издателя; SmartScreen может предупреждать о файле. Обновление выполняется вручную.
