# ESXi RAID Assistant 0.2.2 — предварительная версия

- Новая иконка встроена в EXE и окно; доступны отдельные PNG и ICO.
- Если Microsoft Edge WebView2 Runtime отсутствует, программа автоматически скачивает официальный Bootstrapper, проверяет цифровую подпись Microsoft и **спрашивает разрешение перед установкой на этот Windows-ПК**. Необходим интернет, возможно подтверждение Windows. Установка ничего не меняет на ESXi. Если Runtime уже обнаружен, он автоматически не скачивается и не переустанавливается. При ошибках сети доступен официальный Evergreen Standalone Installer x64.
- Исправлена проверка ответов Windows COM при запуске; она могла ошибочно сообщать об отсутствии WebView2 при успешно выполненных вызовах. Неуспешное открытие окна теперь показывает этап и код вместо белого окна. По старому сообщению нельзя определить точную причину ошибки на конкретном ПК.
- Сообщение SSH теперь различает несовпадение ключа и ошибку аутентификации и остаётся рядом с кнопкой. Поддержан однократный парольный keyboard-interactive; дополнительные запросы/OTP не поддерживаются. Ключ SSH всё так же нужно проверить независимо; при несовпадении пароль не отправляется. Не повторяйте неудачный вход много раз подряд из-за возможной блокировки.
- Подсказка для HPE Smart Array использует его собственный PCI ID, а не ID соседнего AHCI. Выбор и совместимость HPE SSACLI и ESXi по-прежнему требуют отдельной проверки.
- Для обычного HTTPS-подключения ESXi не нужны файл сертификата или ручной отпечаток; при недоверенном сертификате показывается предупреждение о риске подмены до отправки пароля.

Windows 10/11 x64. Проверки: Go/SSH-симулятор, 15 браузерных сценариев, Windows WebView2 с локальным имитатором ESXi, отказные сценарии загрузчика и проверка подписи официального Bootstrapper. Проверки не заменяют испытание на вашем Windows-ПК и реальном контроллере ESXi. EXE подписан публичным лабораторным сертификатом из репозитория; подпись не доказывает личность издателя, возможны предупреждения SmartScreen. Обновление самого помощника — вручную.
