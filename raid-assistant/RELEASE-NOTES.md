# ESXi RAID Assistant 0.2.3 — предварительная версия

- MegaRAID SAS Invader с полным PCI ID `1000:005d / 1000:9361` распознаётся как **MegaRAID SAS 9361-8i / SAS3108**, даже если ESXi сообщает неизвестный статус адаптера. Распознавание не доказывает исправность дисков, firmware или совместимость пакета.
- Для 9361-8i автоматический выбор LWA, скачивание и импорт предлагаемого архива заблокированы: [README LSA MR 7.38](https://docs.broadcom.com/docs/1232745888) не перечисляет эту модель. Неперечисленная модель не обязательно несовместима, но подходящий LWA для конкретного ESXi ещё не подтверждён. На хосте с 95xx и 9361 показано, что кандидат относится только к указанной модели 95xx.
- В разделе модели доступны официальные HCL и каталог загрузок, статус обнаружения некоторых имён StorCLI в VIB и команда просмотра состояния для **уже установленного совместимого StorCLI64** на ESXi 8. Наличие имени VIB не подтверждает путь и совместимость. Кнопка открывает необязательное чтение RAID по SSH с отдельной проверкой ключа и разрешением; сервер и RAID программой не изменяются. Не все версии утилит и форматы вывода поддерживаются. Реальный контроллер/хост не проверялся.
- Сохранены иконка, запуск WebView2 с автоматической загрузкой официального Runtime при его отсутствии и согласие перед установкой на ПК, диагностика SSH и однокнопочное подключение ESXi из 0.2.2. Программа не устанавливает пакеты на ESXi и не меняет firewall или RAID.

Windows 10/11 x64. Проверки: Go/race/vet, модельный ESXi API с ID 9361 и неизвестным статусом, браузерные сценарии и Windows WebView2 с локальным имитатором ESXi. CI не заменяет испытания на вашем ПК и реальном контроллере. Установщик WebView2 ранее запускался в Windows CI с уже установленным Runtime; чистая Windows не проверена. EXE подписан публичным лабораторным сертификатом из репозитория; подпись не доказывает личность издателя, возможны предупреждения SmartScreen. Обновление помощника — вручную.
