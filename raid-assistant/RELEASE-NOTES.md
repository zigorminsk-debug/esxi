# ESXi RAID Assistant 0.1.0 — предварительная версия

Отдельная переносимая программа для Windows x64 с локальным HTML-интерфейсом. Подключается к непосредственно ESXi по проверенному TLS, собирает диагностические данные только для чтения и для известных сочетаний Broadcom/LSI MegaRAID и ESXi 8 подготавливает официальный LSA/LWA и персональную ручную инструкцию. Перед загрузкой необходимо лично принять условия Broadcom.

После установки и настройки совместимого LWA доступ может открываться на `https://IP-ESXi:35557`; порт не универсален. Программа не устанавливает VIB, не меняет RAID, SSH или firewall и не перезагружает сервер. При неизвестной совместимости она показывает причину и путь через OEM. Каталог ограничен, firmware, подпись VIB и фактическую поддержку нужно подтвердить самостоятельно.

Добавлен обзор других расширений ESXi 8: StorCLI/StorCLI2, HPE SSACLI/AMS, Dell iSM, OEM-драйверы, NVIDIA vGPU и Veeam CDP. **Их автоматического подбора или установки в этой версии нет.** Подробности — `ESXI-8-EXTENSIONS.md`.

Требуются Windows 10/11 x64 и актуальный Microsoft Edge WebView2 Runtime. Для самоподписанного сертификата ESXi необходимо независимо проверить SHA-256. Сначала прочитайте прилагаемый `README-RAID-Assistant.md`.

EXE подписан публичным лабораторным сертификатом из репозитория по решению владельца. Он не подтверждает надёжно подлинность издателя; SmartScreen может предупредить о файле. Контрольная сумма — в `SHA256SUMS.txt`. Реальный сервер ESXi и RAID-контроллер не были предоставлены для испытания, поэтому совместимость на вашем оборудовании не подтверждена. Автоматического обновления этой утилиты пока нет.
