ТОЛЬКО АНАЛИЗ
!

Отчёт — снимок, а не живая проверка. Уточните, с какого хоста и когда он получен. Файл может содержать чувствительные данные. Команды чтения выполняйте штатной утилитой с подходящей версией для вашего контроллера.

StorCLI2 на ESXi 8 использует ESXCLI-плагин; пакет и синтаксис проверяйте в документации производителя. Поддерживаются не все варианты вывода; неопознанные данные не объявляются исправными.

Получить отчёт по SSH необязательно

Сначала вручную включите SSH в доверенной сети, если политика это разрешает. Помощник не включает службу. Он выполняет только заранее заданные команды просмотра; сам вход и утилиты могут оставлять системные журналы.

Ключ :

Сверьте этот SHA-256 через независимую консоль сервера / iLO / iDRAC. SSH-ключ — не TLS-сертификат порта 443. Например, сравните отпечаток соответствующего публичного файла /etc/ssh/ssh_host_*_key.pub командой ssh-keygen -lf ИМЯ_ФАЙЛА -E sha256.

Пароль очищается из поля после запроса. Для непрерывного мониторинга он остаётся только в памяти до остановки мониторинга/закрытия программы.

Мониторинг остановлен.

Для RAID заполните в разделе выше SSH-логин, пароль, тип утилиты, независимо подтверждённый host key и разрешение. Пароль повторяется только в памяти до остановки. Проверка порта не проверяет RAID. Приложение не работает как служба и не наблюдает за хостом после закрытия.
