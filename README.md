# esxi

ESXi — управление и автоматизация VMware ESXi.

Инструменты для инвентаризации хостов, мониторинга ресурсов и автоматизации через API.

## Статус
Репозиторий очищен. Ведётся разработка ESXi-инструментов.

## Планы
- Инвентаризация хостов и ВМ
- Мониторинг CPU/RAM/хранилища
- Автоматизация развёртывания
